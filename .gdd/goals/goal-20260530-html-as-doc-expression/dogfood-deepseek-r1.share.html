DeepSeek-R1：用强化学习逼出推理能力

一篇证明"推理可以主要靠 RL 习得"的论文——R1 在数学、代码、推理基准上追平 OpenAI o1，且开源、低成本、可蒸馏进小模型。

DeepSeek-AI arXiv:2501.12948 2025-01
问题

推理能力，非得靠海量标注吗

此前的推理增益高度依赖大规模有监督微调（SFT）——需要人工标注的思维链，昂贵且难扩展。这篇论文问的是：推理能力能否仅从强化学习中自行涌现，让模型自己长出反思、验证等行为；以及，如何把这样的模型变得可用、并迁移到更小的模型上。

方法

纯 RL 先跑通，再用冷启动修可用性

工作分两个模型。R1-Zero 对基座（DeepSeek-V3-Base）直接做 RL、完全不用 SFT，用规则奖励（答案正确性 + 格式）和 GRPO 算法——推理行为自然涌现，但输出可读性差、中英混杂。R1 用多阶段管线修这些问题：少量高质量冷启动思维链做 SFT，再做面向推理的 RL，再用拒绝采样 SFT + 最后一轮对齐 RL；最后把 R1 的推理蒸馏进小模型。

  • R1-Zero：对基座纯 RL，无监督预热
  • GRPO：去掉 critic 的 PPO 变体，用组内采样估计 baseline，更省显存
  • 规则奖励：可验证答案 + 格式奖励，不训练奖励模型
  • 冷启动 + 多阶段：CoT 种子 SFT → 推理 RL → 拒绝采样 SFT → 最终 RL
  • 蒸馏：输出蒸馏进 Qwen（1.5B–32B）与 Llama（8B / 70B）
结果

在竞赛数学上追平 o1

R1 在多数推理基准上与 o1-1217 同档；最亮眼的是竞赛数学 AIME 2024，pass@1 达 79.8%，略胜 o1 的 79.2%。蒸馏出的 32B / 70B 在若干基准上超过 o1-mini。

启示与局限

意义，与该打的折扣

  • RL 能直接逼出推理（R1-Zero 完全不用 SFT），挑战了"必须靠大规模 SFT"的假设，且报告的后训练成本低一个量级。
  • 开源权重 + 六个蒸馏小模型，把接近前沿的推理能力大幅普及——这是 2025 年初行业震动的直接原因。
  • 诚实的代价：R1-Zero 纯 RL 输出可读性差、中英混杂；完整 R1 的冷启动 + 多阶段管线正是为修这些可用性问题而存在。
  • 其它局限：R1 对提示敏感（few-shot 反而掉点，建议 zero-shot）、非中英查询有语言混杂、部分软件工程任务增益较弱。
