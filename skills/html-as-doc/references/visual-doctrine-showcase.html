D2 能画什么

同一张图三种画法横向对比：D2（自定义 DSL，最贴近"diagram-as-code"思路）· Mermaid（mmdc 离线编译，配了 Apple 调色板的 themeVariables）· 手写 inline SVG（v4.1 那一套）。下面折叠了 D2 源码。

D2 不擅长的 / 不该用的

  • 数据图表（bar / line / scatter / histogram） —— 没有数据轴概念。走 Vega-Lite。
  • Gantt / timeline / 甘特图 —— Mermaid 有原生支持，D2 没有。
  • Mind map / 思维导图 —— 能凑活画成树，但 Mermaid / PlantUML 有专门语法更省事。
  • UI mock（侧栏、卡片、按钮的视觉摹仿） —— D2 的 shape primitive 太抽象，画不出真实 UI 质感。走 Satori 或直接写 HTML/CSS。
  • 需要跟 CSS 主题色实时联动的图 —— D2 输出颜色编译时固定。要 dark mode 得跑两次或写 sed 脚本。继续走"手写 SVG + data-k" 方案。
  • 自由插画 / 手绘风 —— 走 Excalidraw / tldraw。

额外能力（懒得各开一节）

  • 主题 / themeID —— d2 --theme=200 file.d2 file.svg，内建几十套，包括 dark / sketch 风。
  • 布局引擎切换 —— --layout=elk（精确） vs dagre vs tala（付费），同一 DSL 不同审美。
  • tooltips —— nodeX.tooltip: "解释文字"，SVG 输出自带 hover 气泡，不需要外部 JS。
  • links —— nodeX.link: "https://..."，节点变可点击锚链接。
  • icon —— nodeX.icon: https://icons.example/aws-s3.svg，自动嵌入。AWS / GCP / Kubernetes icon pack 现成。
  • animated arrow —— style.animated: true，SVG SMIL 动画自动加。handoff 里可以让数据流动起来。
  • 多张图共享变量 —— vars: { primary: "#0066CC" } 后所有 fill 引用 ${primary}。换主题改一处。
  • compose —— D2 文件可以 import 其它 D2 文件做组件复用，适合大型架构图。
